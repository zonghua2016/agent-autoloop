# Autoloop 本机管理看板

使用 Node 24，在仓库根目录启动独立客户端：

```sh
node examples/recipes/live-dashboard/server.mjs /absolute/private/config.json
# 指定端口，并强制只读：
node examples/recipes/live-dashboard/server.mjs /absolute/private/config.json 5419 --readonly
```

打开 http://127.0.0.1:5419/，使用本机 `config.json` 的 `owner` 密钥登录。会话有效期 12 小时，右上角「退出登录」立即撤销；重启看板也会使旧会话失效。登录后默认管理可写，`--readonly` 在服务端拒绝所有写操作。只监听本机，中台地址也必须是回环地址。本人密钥仅在登录时提交，不写入浏览器持久存储；浏览器通过随机 CSRF 令牌、精确 Host 和同源 Origin 校验提交白名单操作。提交结果未知时不自动重发，先刷新核对。

卡片可选项回答、文字回答或结案；轮次可请求停止；规则可暂停、恢复、立即运行和补跑。飞书事项自动发现所有配置了 tasks.personal.owner 且获准的本人通道，允许取消尚未派发的待补充/待确认草稿；正在派发的草稿不能取消，防止结果未知时误报。卡片禁用状态由飞书消费者同步。

七个站点包含池中 DeepSeek 鲸鱼和栈道 Gemini 双星，两个角色共存。接单站固定使用 Codex 造型，巡检站固定使用巡检小车；站牌显示实际接单程序名称，任务切换与空闲不会改变站点造型。最多八个在轨包裹、每站三个泊位，超额显示数量。新卡片、回答、执行、重试和结果沿事实触发的路线播放，列表始终显示最新状态。点击建筑或包裹查看详情，支持跟拍、有限平移和 R 键复位。保持原来的绘制节奏，隐藏标签页暂停渲染。

六个分类带实时计数，支持搜索和项目筛选；规则与健康展示通道、定时、暂停和消耗。正在填写的表单与展开的时间线保留。夜景采用深色控件，窄屏可横向滚动分类。天气设置可以关闭联网请求并保留本地昼夜。

多个浏览器标签共享一条中台 SSE 和短时快照缓存；卡片直接用 runId 查询来源。写操作通过标准 /v1 接口，不访问 hub.db；只有取消草稿写入插件自己的任务库。关闭服务会停止订阅、连接与定时器。

验证：`node --test tests/dashboard*.test.ts examples/recipes/live-dashboard/server.test.mjs`。使用临时数据库、随机端口和本地假中台，不向飞书发送真实消息。
